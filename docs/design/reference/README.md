# Maquette de référence MaintiDoc — direction « Technicien »

Fichiers HTML statiques validés par l'utilisateur. Ce sont la RÉFÉRENCE VISUELLE
de l'interface Streamlit (couleurs, typographie, espacements, composants).
Ouvrir dans un navigateur à 1440×900 (thème clair).

- 1-assistant.html — page Assistant (chat, réponse vérifiée, sources, chargement)
- 2-recherche-image.html — page Recherche par image
- 3-document.html — page Document
- 4-composants.html — logo, couleurs, boutons et leurs 6 états, cartes, champs, typo

Les zones entre crochets [ … ] sont des emplacements (vraies images / vrais textes dans l'app).
